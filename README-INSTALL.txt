PORTFOLIO SEO PAGES — INSTALLATION

1. Upload all files in this package to the ROOT of the GitHub Pages repository (same directory as your current index.html).
2. Do NOT replace or delete your existing index.html or 3D assets.
3. Add the navigation links from the included pages to your existing index.html.
4. In your existing index.html <head>, replace duplicate favicon declarations with:
   <link rel="icon" href="/favicon.ico" sizes="any">
   <link rel="icon" type="image/png" sizes="48x48" href="/favicon-48.png">
   <link rel="icon" type="image/png" sizes="192x192" href="/favicon-192.png">
5. Edit contact.html to add your real LinkedIn / other public profiles if desired.
6. Verify exact bibliographic titles and DOI links in research.html before publishing those citations.
7. Verify all pages load on your custom domain, then submit sitemap.xml to Google Search Console.
8. The files use root-relative URLs; they are designed for joseluisromerovazquez.lat, not the temporary /portfolio/ project path.
